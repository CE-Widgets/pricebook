# Release notes

## 2026.11.12-24 — Internal-test build

- Added typed-list, dictated-list, and manual purchase entry workflows.
- Added review, correction, confirmation, and rejection before saving parsed
  purchases.
- Added product-history browsing, comparison of like quantities within a unit,
  and edit/delete controls for saved purchases.
- Uses Firebase App Check with Google Play Integrity and the production service
  route for the internal test.
- Added limited, content-free first-party telemetry. It excludes purchase text,
  recordings, transcripts, product/store names, quantities, prices, and dates.

This build is available only through the Google Play internal testing track.
It is not a public production release.
