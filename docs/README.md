## Data summary

Saved price history is local to the Android device. There is currently no cloud
sync, export, or recovery. Typed lists are sent to OpenAI for parsing only when
the user requests review. A dictated recording is sent for transcription only
after the user taps Stop, and the application deletes the recording after a
successful or failed transcription. See the Privacy Policy before entering
information the user does not want processed.
