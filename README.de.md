## Wissen, was Sie bezahlt haben. Ihre Historie vergleichen.

Personal Price Book ist eine Android-App, mit der Sie Ihre eigenen Einkäufe und Preise einfach festhalten können. Sie können eine Einkaufsliste eingeben, diktieren oder einen Kauf manuell erfassen, die erkannten Details vor dem Speichern prüfen und Ihre eigene Kaufhistorie beim nächsten Einkauf vergleichen.

Die App ist eine persönliche Referenz und kein Preisfeed von Händlern. Gespeicherte Preishistorie bleibt auf dem Gerät; es gibt derzeit keine Cloud-Synchronisierung, keinen Export und keine Wiederherstellung.
