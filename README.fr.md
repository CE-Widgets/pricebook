## Sachez ce que vous avez payé. Comparez votre historique.

Personal Price Book est une application Android qui permet de garder un historique simple de vos propres achats et prix. Saisissez ou dictez une liste, ou ajoutez un achat manuellement ; vérifiez les détails reconnus avant de les enregistrer, puis comparez votre propre historique lors du prochain achat.

L’application est une référence personnelle, et non un flux de prix des commerçants. L’historique enregistré reste sur l’appareil ; il n’existe actuellement ni synchronisation dans le cloud, ni exportation, ni récupération.

La documentation complète et les informations juridiques sont disponibles en [anglais](README.md).
